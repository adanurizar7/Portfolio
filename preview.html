Fraud detection model

Machine learning class case, team of 5, fall 2026

A bank was getting four times more account applications after launching a $200 sign-up bonus, and fraud grew with them. We built a model that scores every application the moment it's submitted, so the riskiest ones go to manual review.

I built my own logistic regression, then combined my teammates' feature ideas into 55 candidates and narrowed them to the 20 that mattered, using statistical tests and stepwise selection on about 212,000 applications.

Accuracy (AUC)
0.844 vs. 0.651 for the bank's current score
Fraud caught
48% while reviewing only 7% of applications
Estimated cost
$1.03M to $0.71M about 31% lower
