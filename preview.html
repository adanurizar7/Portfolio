Featured project

Fraud detection models

Machine Learning, Wake Forest MSBA, fall 2026. Team of 5, class case

A bank was getting four times more account applications after launching a $200 sign-up bonus, and fraud grew with them. We built models in Python that score each application the moment it's submitted, using about 212,000 applications and 110 features from a 43-table bank database.

We started with a logistic regression, then built a random forest and an XGBoost model tuned with Optuna. XGBoost won on every business measure, so it's our final recommendation.
